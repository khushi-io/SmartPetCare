# 🌟 About The Project

**SmartPetCare** is an intelligent pet healthcare and management platform designed to help pet owners manage their pets efficiently through a modern digital system.

The platform provides smart features like:

✨ Pet health tracking  
✨ User authentication system  
✨ Vaccination & care management  
✨ Responsive dashboard  
✨ Secure database handling  
✨ Smooth and modern UI  

Built as an innovative hackathon solution using **Django** and **Python**.

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/khushi-io/smartpetcare.git
cd smartpetcare
```

---

## 2️⃣ Create Virtual Environment

```bash
python -m venv venv
```

---

## 3️⃣ Activate Environment

### Windows
```bash
venv\Scripts\activate
```

### Linux/Mac
```bash
source venv/bin/activate
```

---

## 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 5️⃣ Run Migrations

```bash
python manage.py migrate
```

---

## 6️⃣ Start Server

```bash
python manage.py runserver
```
